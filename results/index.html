Results

What has been proven, and where each result stands.

Each result is a computer-checked proof that improves a published bound on an open problem. Each one has a page that explains it in plain English. Published results come with a full package anyone can download and re-check; results marked “package coming” already come with a short check-it-yourself kit.

In progress

Every result moves through five stages. The four published results are at stage 3; the verified result above is at stage 2.

1. FoundThe system found a candidate and it passed a first rigorous computer check.
2. VerifiedIndependent checkers, a formally verified checker or Lean proof where possible, hostile AI review, a literature check and a 48-hour hold.31
3. PublicThe authors of the prior work are told first. Then the note and code go public with a DOI.#188, #189, 228, 276
4. arXivA written paper on arXiv, ideally with a professional mathematician as co-author.
5. Peer-reviewedAccepted by a journal after independent review.

More results are in preparation. A result reaches stage 3 only after the authors of the work it builds on have had a chance to look, and its package has a DOI. A result is marked expert-checked when an independent mathematician has checked it; none has that mark yet.

Caught before publishing

Things that looked new or true at first, until the checks said otherwise. None of these were ever published; they were caught before anything went public. They are listed because catching them is the point. Items about unpublished work will be added when that work is published.

  • A claimed 63 for #188 (2 Oct 2026). The search had graded itself on a sample of lines; the true figure was at least 68. Never announced. Evidence
  • A 5-chromatic unit-distance graph in a small disk (20 Sep 2026) was already beaten in the Polymath16 project in 2021. Evidence
  • A theorem overtaken by Tomon's paper (arXiv:2610.03517, 2 Oct 2026), found before release. Dropped. Evidence
  • An exact value already proved by Cabello in 2012 (arXiv:1112.5149). Dropped. Evidence
  • Table entries first counted as new that followed from graphs Cherkashin, Kulikov and Raigorodskii had already published. Evidence
