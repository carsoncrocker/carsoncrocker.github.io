Erdős Problem #189

Color every point of the plane with one of two colors. Must there be a rectangle of area exactly 1, of any shape and tilted any way, whose four corners all have the same color? Yes. In fact 180 specific points already force one.1

r ≤ 21, only the trivial r ≥ 2→3 ≤ r ≤ 21

Package and note: doi:10.5281/zenodo.23178517. Computer-checked, with a Lean proof; not yet reviewed by a mathematician.

What was known

Erdős Problem #189 asks whether, in every coloring of the plane with finitely many colors, one color contains the corners of rectangles of every area.2 Kovač showed that the answer is no: he colored the plane with 25 colors so that no rectangle of area 1 has four corners of one color.3 Hu and Liu brought 25 down to 21 and asked for the smallest number of colors r that can do this.4 So r ≤ 21, and as far as I could find, nobody had shown that two colors are not enough.1

What is new

Every two-coloring of the plane has a rectangle of area 1 with four corners of one color. So two colors are never enough, and the smallest r satisfies 3 ≤ r ≤ 21.1 To my knowledge this was not in the literature before; the note asks to be corrected if it was.1

The idea in simple words

If two colors could avoid such rectangles on the whole plane, they could also avoid them on any finite set of points. So it is enough to find one finite set of points that cannot be two-colored without a one-color rectangle of area 1.

The points come from a scaled triangular grid. On this grid, rectangles of area 1 come in very few shapes, 12 up to shifting, so the rectangles through each point overlap heavily, which helps a small set to work.1 The final set has 180 points and contains exactly 676 rectangles of area 1.1

Each rectangle gives a rule: "these four points are not all the same color". A SAT solver shows the rules cannot all hold at once and writes out a proof file that standard tools can check. The set is also as lean as it can be in one sense: remove any one of the 180 points and a valid coloring exists.1 The approach is the one Moore and Sagdeev used for unit rhombi.1

How it was checked

  • The geometry: a checker using whole-number arithmetic only finds all area-1 rectangles in three different ways, requires them to agree, rebuilds the formula from them and compares it, clause by clause, with the published one.5
  • The proof: verified by drat-trim and lrat-check, a second proof from a different solver is also verified, and the proof passes cake_lpr, a formally verified checker.6
  • Lean: a sorry-free Lean 4 proof of the two-color statement. Its SAT step uses Lean's bv_decide, which trusts Lean's compiled code alongside the kernel.7
  • Outside AI referee: ChatGPT rebuilt the 676 rectangles and the formula with its own code and re-solved it with a different solver.8

The checkers were written with Claude Code in separate sessions, which is not independence in the sense of different authors. No expert has checked the work yet, and independent checks are very welcome.9

How to check it yourself

Download the package from doi:10.5281/zenodo.23178517, unzip it, install drat-trim and lrat-check, and in Linux or WSL run:5

bash verify.sh        # about 5 minutes, Python standard library only

The last line says PASS or FAIL. bash verify.sh full also checks the second proof. The Lean proof is in the folder lean/.

What is not claimed

  • It does not answer Erdős's original question for two colors. By scaling, every area appears in one color or the other, but which color may depend on the area.1
  • It does not show that any single rectangle shape is forced: the proof uses four shapes together.1
  • Three colors (r ≥ 4) is open.1
  • 180 is the smallest set I found, not a proven minimum size.1
